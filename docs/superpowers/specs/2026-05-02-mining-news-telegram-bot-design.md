# Дизайн: Telegram-бот для новостей горной промышленности

## Цель

Создать первую версию системы автоматизации для тематического Telegram-канала про новости горной промышленности.

Основной фокус канала: Россия и страны СНГ. При этом канал может брать важные мировые новости, если они полезны русскоязычной отраслевой аудитории.

Первая версия должна помогать готовить короткие новостные посты, но не должна публиковать их без подтверждения человека.

## Формат поста

Каждый подготовленный пост должен быть коротким и удобным для Telegram:

- заголовок;
- 3-5 коротких предложений;
- ссылка на исходный источник.

Текст должен кратко пересказывать исходную новость. Бот не должен добавлять неподтвержденные выводы, догадки или факты, которых нет в источнике.

## Как проходит публикация

Бот работает по такой схеме:

1. Несколько раз в день система проверяет настроенные источники новостей.
2. Она находит новые публикации.
3. Фильтр убирает неподходящие новости и повторы.
4. Генератор готовит короткий черновик поста на русском языке.
5. Бот отправляет черновик модератору в Telegram.
6. Модератор выбирает действие:
   - опубликовать пост в канал;
   - отклонить пост.
7. Система запоминает обработанные новости, чтобы не предлагать одно и то же повторно.

Рекомендуемое расписание для первой версии: три проверки в день, например в 09:00, 14:00 и 19:00 по московскому времени.

## Источники

В первой версии используем открытые веб-источники:

- RSS-ленты отраслевых СМИ;
- новостные страницы горнодобывающих компаний;
- публичные страницы госорганов и регуляторов;
- пресс-релизы;
- выбранные международные источники про горную промышленность.

В первой версии не парсим чужие Telegram-каналы. Так меньше риск копирования чужого контента, публикации низкокачественных пересказов и появления дублей.

## Основные части системы

### Конфигурация источников

Список источников хранится в отдельном конфигурационном файле.

Для каждого источника указываем:

- название источника;
- ссылку;
- тип источника, например RSS или обычная веб-страница;
- регион или категорию, если нужно;
- включен источник или временно отключен.

Такой подход упрощает поддержку: новые источники можно добавлять без изменения основной логики программы.

### Сборщик новостей

Сборщик проверяет настроенные источники и извлекает найденные новости.

Для каждой новости он сохраняет:

- заголовок;
- ссылку на источник;
- дату публикации, если она есть;
- короткий текст или фрагмент статьи;
- название источника.

### Фильтр дублей

Система хранит ссылки уже обработанных новостей в локальной базе данных.

Для первой версии достаточно проверки дублей по ссылке. Позже можно добавить более умную проверку, чтобы находить одну и ту же новость, опубликованную на разных сайтах.

### Тематический фильтр

Тематический фильтр оставляет только новости, связанные с горной промышленностью и близкими промышленными темами.

Подходящие темы:

- добыча полезных ископаемых;
- уголь, золото, медь, никель, железная руда, редкоземельные металлы, алмазы, уран и другие виды сырья;
- горнодобывающие компании и проекты;
- шахты, карьеры, ГОКи, обогатительные фабрики;
- горная техника и промышленные технологии;
- промышленная безопасность, аварии, проверки и регулирование;
- экологические требования, связанные с добычей;
- сырьевые рынки, если новость напрямую влияет на горнодобывающие компании или проекты.

Неподходящие темы:

- общие финансовые новости без связи с добычей;
- обычная политика без связи с отраслью;
- строительство, логистика или энергетика без отношения к горной промышленности;
- реклама и спонсорские материалы.

### Генератор черновиков

Генератор готовит короткий русскоязычный Telegram-пост на основе исходной новости.

Инструкция для генератора должна требовать:

- использовать только факты из источника;
- писать кратко;
- не делать кликбейт;
- не добавлять неподтвержденные выводы;
- добавлять ссылку на источник;
- сохранять важные названия, цифры, места и даты.

### Telegram-бот

Telegram-бот выполняет две задачи:

- отправляет черновики модератору;
- публикует одобренные посты в публичный канал.

Под каждым черновиком должны быть кнопки:

- Опубликовать;
- Отклонить.

В будущей версии можно добавить кнопку "Перегенерировать", но для первого запуска она не обязательна.

### База данных

Для первой версии используем SQLite.

База должна хранить:

- ссылки на обработанные новости;
- текст сгенерированного черновика;
- данные об источнике;
- статус черновика: ожидает проверки, опубликован или отклонен;
- время создания и модерации.

SQLite подходит для старта, потому что система небольшая и может работать на одном сервере.

## Обработка ошибок

Бот должен спокойно обрабатывать типовые проблемы:

- если один источник временно недоступен, продолжить проверку остальных;
- если генерация текста не удалась, сохранить ошибку и перейти к следующей новости;
- если Telegram не смог опубликовать пост, оставить черновик без изменения статуса, чтобы публикацию можно было повторить;
- записывать ошибки в понятный лог.

Система не должна публиковать неполные или сломанные посты.

## Настройки и секретные данные

Секретные данные нельзя хранить прямо в коде.

К ним относятся:

- токен Telegram-бота;
- ID Telegram-канала;
- ID чата модератора;
- ключ OpenAI API или другого сервиса генерации текста.

Эти значения нужно читать из переменных окружения или локального файла `.env`, который не попадает в git.

## Что входит в первую версию

Входит:

- приложение на Python;
- интеграция с Telegram Bot API;
- база SQLite;
- настраиваемый список источников;
- проверка источников по расписанию;
- генерация черновиков;
- ручная модерация;
- публикация в канал после подтверждения;
- базовая защита от дублей;
- базовое логирование.

Не входит:

- парсинг чужих Telegram-каналов;
- автоматическая публикация без модерации;
- веб-админка;
- сложная аналитика;
- платные подписки;
- умное объединение дублей с разных сайтов;
- работа нескольких редакторов с разными правами.

## Критерии успеха

Первая версия считается готовой, когда:

- бот проверяет настроенные источники несколько раз в день;
- новые подходящие новости про горную промышленность превращаются в короткие черновики;
- черновики приходят модератору в Telegram;
- одобренные черновики публикуются в канал;
- отклоненные черновики не публикуются;
- одна и та же ссылка не предлагается повторно;
- секретные ключи не хранятся в репозитории.
